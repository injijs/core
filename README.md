# @injijs/core

Zero-dependency TypeScript library for ESC/P 24-J84 dot-matrix impact printers.

ESC/P 24-J84（24ピン漢字ドットインパクトプリンタ）向けの、外部依存ゼロ・Universal 対応の TypeScript 印字制御ライブラリです。

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp pack
```
